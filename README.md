# ROUTINE-CREATOR-SITE-PROJECT


A simple Flask-based web application that helps users **plan their daily routines**, manage tasks, and explore **daily routines followed by well-known individuals**.
## CORE DESCRIPTION

This project was built with a dual purpose: **improving personal productivity** and **learning practical web development through hands-on implementation**.

At its core, the idea is simple — most people struggle with consistency, not knowledge. Instead of just creating another basic to-do list, this application connects **daily task management with real-world routines followed by high-performing individuals**. By doing this, users are not only organizing their day but also gaining insight into how structured routines can impact discipline, health, and long-term growth.

This project also reflects a practical mindset:

> Small, consistent actions build systems — and systems shape outcomes.



Ultimately, this project serves as:

* A **learning milestone** in web development
* A **tool that promotes disciplined daily living**

##  Features

* 📋 Create your own daily tasks with:

  * Task name
  * Description
  * Deadline / time

* 🌟 Explore routines of well-known personalities:

  * Bryan Johnson
  * Dwayne Johnson
  * Dr. Rhonda Patrick
  * Dr. David Sinclair
  * Dr. Gaurang Krishna

* 🧠 Combines productivity with inspiration by allowing users to:

  * Follow structured routines
  * Build their own daily systems

## ▶️ How to Run Locally

1. Clone the repository:

```
git clone https://github.com/your-username/your-repo-name.git
```

2. Navigate into the project folder:

```
cd your-repo-name
```

3. Install dependencies:

```
pip install flask
```

4. Run the app:

```
python app.py
```

5. Open in browser:

```
http://127.0.0.1:5000/
```
